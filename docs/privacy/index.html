Privacy Policy – rclone-jonas

Last updated: 23 October 2026

rclone-jonas is a private Google API client used only by João Blasques, the owner of joaoblasques.com, to copy his own files between his own computers and his own Google Drive with the open-source tool rclone. It is not offered to anyone else.

What data it accesses

Only files in the owner's own Google Drive: the folders the tool creates for backups and file copies, and one inbox folder the owner uses to send files from his phone to his computer.

How the data is used

Files are copied between the owner's computers and the owner's Google Drive. Nothing else is done with them.

Sharing and storage

No data is collected by, sent to, or stored on any server other than Google Drive and the owner's own computers. No data is shared with third parties, sold, or used for advertising or analytics.

Google API Services User Data Policy

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

Access can be revoked at any time at myaccount.google.com/permissions.

Contact

Questions: see the contact details on joaoblasques.com/about.
